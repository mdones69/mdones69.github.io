Privacy Policy

This application is a personal, single-user application used to manage personal backups.

Information Collection

This application does not collect, sell, or share personal information with third parties.

Google Drive Access

The application uses Google Drive access solely to store and manage the owner's personal backup files. Access is authorized through Google's OAuth system.

Data Storage

Backup files are stored in the owner's Google Drive account. No backup data is intentionally collected or stored by this website.
